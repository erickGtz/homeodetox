# ADR 0002 — CMS: MDX ahora, Sanity después

- **Estado:** propuesto
- **Fecha:** 2026-11-03

## Contexto

El cliente necesita publicar servicios, productos, eventos y blog. En fase 1 el
presupuesto no contempla un CMS y el volumen de contenido es bajo.

## Decisión

Usar MDX + Zod detrás de `src/lib/content/`. Evaluar Sanity en una fase posterior sin
cambiar páginas ni componentes.

## Consecuencias

- Costo cero y contenido versionado.
- Edición requiere conocimientos básicos de Markdown y Git.
- La capa de contenido debe mantenerse aislada para permitir el cambio de origen.
